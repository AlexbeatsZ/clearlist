# Todo清单参考分析

分析日期：2026-10-19。对象为本机已安装的 Windows Todo清单 3.14.2，位置为 `C:\Program Files\todo-list\resources\app.asar`。仅以只读方式检查 ASAR 目录、软件包元数据、页面标识、可见文案和数据库建表描述，没有读取个人任务数据库、登录状态或网络凭据，也没有连接原厂服务。

## 可确认的结构

- Electron 桌面宿主；渲染资源划分为主窗口、共享模块与桌面日历组件，页面代码包含 Vue 风格组件定义。
- 主要工作流：今天、最近待办、待办箱、分类清单、标签、搜索、日历、已完成、回收站、任务统计与番茄专注。
- 任务属性覆盖标题、描述、完成和删除状态、创建和更新时间、计划日期、提醒、排序与重复相关扩展字段。代码存在子任务、置顶、批量移到今天、重复任务编辑范围等交互入口。
- 主进程中存在 SQLite 任务表和元信息表定义；发行包依赖中包含加密 SQLite 库。此观察不表示已解密、读取或兼容其实际数据格式。
- 存在主窗口和小组件间任务更新广播、提醒、番茄悬浮窗和云端同步相关入口。只确认入口存在，未验证其运行行为。

## 简清的实现取舍

| 参考工作流           | 初版独立实现                                   |
| -------------------- | ---------------------------------------------- |
| 今天 / 最近 / 待办箱 | 今天含逾期；最近七天；无日期收集箱             |
| 分类 / 标签 / 搜索   | 彩色清单、任务标签、全局文字与标签搜索         |
| 任务 / 子任务        | 标题、备注、日期、优先级、子任务、置顶、排序   |
| 重复任务             | 完成时生成下一次，按日 / 周 / 月重复，保留历史 |
| 日历                 | 月历，拖动更改日期，点击日期添加任务           |
| 番茄钟 / 统计        | 可恢复的专注计时、任务关联、真实完成与专注统计 |
| 已完成 / 回收站      | 历史浏览、软删除与恢复                         |
| 云端存储             | 首版使用独立本地文件和 JSON 导入导出           |
| 补充视图             | 增加四象限，按重要性和到期状态分配             |

首版不承诺原厂账号、云同步协议、数据库导入、微信提醒、AI、桌面小组件或移动端等价兼容。后续需要实际工作流反馈再推进。
