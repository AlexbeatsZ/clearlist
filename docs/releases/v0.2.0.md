# 简清 0.2.0

暗色模式、Android 手机版本、macOS 双架构版本，以及给本机 AI 使用的 REST API。

## 本次新增

- 暗色配色与表面层次重新整理，启动时读取上次外观；支持浅色、深色和持续跟随系统。原生系统栏和输入控件同步切换。
- 手机底部导航、全屏任务详情、适合触摸的操作区域和安全区布局。Android APK 内置页面、私有原子存储、备份恢复和系统 JSON 文件选择器，离线可用。
- macOS Apple Silicon / Intel 的 DMG 和 ZIP，原生菜单、Cmd 快捷键与关闭窗口后保留 Dock 的行为。最低 macOS 13。
- 桌面本机 API：任务、清单、标签、子任务、搜索、专注、统计和备份导入导出。Bearer 认证、固定 loopback 监听、OpenAPI 文档和自动读取本机配置的 CLI。
- 界面与 API 使用统一状态队列；不同字段并发修改可合并，同一字段冲突会明确提示，保存失败不会广播成功状态。

## 使用 AI 接口

启动 Windows 或 Mac 版本，在设置 → AI 接口复制实际地址和访问令牌。默认地址 `http://127.0.0.1:49721/api/v1`，端口占用时自动调整。

源码目录运行 `npm run ai -- GET "/tasks?view=today"` 即可读取今天任务。创建任务可用 `npm run ai -- POST /tasks --body-file task.json`，其中 JSON 至少包含 `title`。完整说明与 OpenAPI 见 [API 文档](../api/README.md)。令牌仅留在本机用户数据目录，不包含在导出数据中。

## 数据与边界

保持 v1 JSON 兼容，不改动原 Todo清单或其个人数据。各设备数据独立，通过 JSON 显式转移，当前没有自动同步或 iOS 安装包。

Windows 包尚无代码签名；Mac 包使用 ad-hoc 签名、未通过 Apple 公证。Android APK 使用稳定本地发布签名，升级时须保留私钥。

构建、自动化界面检查和实体设备验收分开记录。Android 安装、原生文件选择器、返回键、系统栏，以及下载后的 Mac Gatekeeper 体验尚未人工验收，详见 [验证记录](../verification.md)。
