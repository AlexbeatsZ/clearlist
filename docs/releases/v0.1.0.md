## 简清 / Clearlist 0.1.0

简清的第一个公开版本：一个离线优先、无需账号的开源待办与专注工具，采用 MIT 许可证。

### 下载与使用

Windows x64 用户下载附件 **`Clearlist-0.1.0-Windows-x64.exe`** 后直接运行，无需安装 Node.js。首次解压启动可能需要几秒钟。初次启动为空白清单，可以选择添加入门示例。

用户数据保存在 `%APPDATA%\Clearlist`。建议在设置中定期导出 JSON 备份。

### 首版功能

- 今天（含逾期）、最近七天、全部任务和无日期收集箱。
- 彩色清单、标签、搜索、备注、子任务、优先级、置顶与拖动排序。
- 按日、周、月重复；完成后生成下一次并保留历史，月底日期保留锚点。
- 月历拖动改期、四象限、已完成记录和回收站恢复。
- 任务关联的专注与休息计时、暂停恢复、历史记录和七天统计。
- 浅色、深色、跟随系统、键盘操作，以及本地文件保存、备份恢复和 JSON 合并导入导出。

### 已知范围

这是离线初版，尚无多设备同步、Android/iOS 安装包、定时任务提醒、附件、原应用数据迁移、桌面小组件或自动更新。应用完全关闭期间不发送专注结束通知。Windows 便携版暂未代码签名；macOS 和 Linux 安装包尚未构建与验证。
